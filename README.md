Taxi Pro (Django pet-project)

Локальний pet-проєкт сервісу таксі на Django + DRF + Leaflet.
Проєкт робився ітеративно, з фокусом на робочий MVP, а не на "ідеальний" продакшн.

## Що вже реалізовано

- авторизація (Telegram login (треба едітнути код або переробити логін) + класична форма логін/пароль);
- ролі користувача: `passenger` і `driver`;
- карта на Leaflet з вибором старту/фінішу;
- пошук адреси через Nominatim;
- побудова маршруту через OSRM;
- розрахунок ціни по тарифу (`economy`, `standard`, `comfort`);
- створення замовлення з підтвердженням перед відправкою;
- вибір типу оплати: готівка або картка;
- редірект на checkout при оплаті карткою;
- профіль водія (телефон, авто, номер, опис);
- список онлайн-водіїв + ручний вибір водія;
- бот-водії, що "рухаються" по мапі для демо;
- авто-призначення найближчого онлайн-водія, якщо пасажир не обрав конкретного.

## Технічний стек

- Python / Django / Django REST Framework
- SQLite (локально)
- Leaflet + OpenStreetMap
- OSRM API (маршрути)
- Nominatim API (геокодинг)
- Stripe API (checkout для картки)


## Локальний запуск

1. Створити віртуальне оточення та встановити залежності:
   - `pip install -r requirements.txt`
2. Заповнити `.env` (мінімум: секрети Django, Telegram, Lemon Squeezy).
3. Накатити міграції:
   - `python manage.py migrate`
4. Запуск:
   - `python manage.py runserver`

## Важливий статус по проєкту

Проєкт на поточному етапі, скоріше за все, може не встигнути стабільно "аплоадитись"/задеплоїтись у бажаний термін через брак часу на доведення платіжного флоу до production-ready стану та через невдалий початковий вибір мерчанта (довелось робити міграцію платіжної інтеграції в процесі).
